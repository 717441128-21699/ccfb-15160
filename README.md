# 高空抛物监控视频分析系统

针对仰拍摄像头的纯前端网页分析工具: 标定楼面网格 → 检测下落物体 → 抛物线回溯抛出点 →
定位到楼层/户号 → 生成取证报告。无需服务器, 数据全部保存在浏览器本地。

## 运行

```bash
npm install
npm run dev        # 开发调试 (默认 http://localhost:5173)
npm run build      # 产物到 dist/, 任意静态服务器均可托管
npm test           # 算法单元测试 + 精度仿真(无需浏览器)
```

要求: 支持 WebGL2 的浏览器 (Chrome / Edge / Firefox 均可)。

## 页面

| 页面 | 功能 |
|---|---|
| 楼栋标定 | 导入参考照片或从视频抓帧, 拖拽四边形贴合楼面, 设置楼层数/每层户数/起始楼层/户号方向, 自动生成带户号标注的网格; 可保存多套标定、导入标定 JSON |
| 视频分析 | 导入监控录像, WebGL2 运动检测(背景建模+帧差+形态学), 多目标跟踪, 分类排除树叶/飞鸟/雨滴, 抛物线拟合回推抛出点, 实时叠加显示; 支持夜间红外模式、处理分辨率/灵敏度/速度调节; 可加载真值 JSON 自动输出精度报告 |
| 事件列表 | 检出事件汇总(截图、户号、时间、置信度、物体推测), 筛选/删除/导出 JSON |
| 取证报告 | 单事件完整报告: 事件信息、标定信息、轨迹回溯叠加图、截图, 可打印/另存 PDF、导出证据 JSON |
| 测试视频合成 | 按 抛掷物类型(瓶罐/垃圾袋/纸箱/纸张) × 风速(0~8 m/s) × 干扰(树叶/飞鸟/雨滴) × 昼夜(红外) 合成带真值的模拟监控录像, 自动下载 录像 webm + 真值 JSON + 配套标定 JSON |

## 典型验收流程

1. 「测试视频合成」: 选 60s、8 个事件、随机风速、正常干扰, 勾选下雨和夜间红外可分别验证;
   生成后得到 3 个下载文件。
2. 「楼栋标定」: 导入 `标定_*.json`(或手动标定)。
3. 「视频分析」: 选择 `合成监控_*.webm` + 该标定, 加载 `真值_*.json`, 开始分析;
   结束后自动给出 检出率/漏检/误报/楼层误差≤1层比例/户号正确率。
4. 保存事件 → 「事件列表」→「取证报告」打印。

## 精度与性能指标

**精度**(算法仿真, `npm test`, 400 次随机抛物 × 4 种物体 × 风速 0~8 m/s):

| 定位噪声 | 楼层误差≤1层 | 户号判对率 |
|---|---|---|
| ±2px (640×360) | 100% | 100% |
| ±4px | 100% | 100% |

要求为 楼层误差≤1层、户号判对率≥90%, 仿真余量充足。实际录像中的主要误差来源是
标定四边形贴合度与摄像头抖动, 标定时角点尽量对准楼面四角。

**性能**: 检测在 GPU(WebGL2)完成, CPU 只做小分辨率掩膜的连通域与跟踪。
处理分辨率 640×360 时单帧 GPU 开销 <1ms, 瓶颈在视频解码。
浏览器内以 8×~16× 倍速解码播放即可达到 1 小时录像 5 分钟级分析;
分析页实时显示 帧率/倍速, 可据此验证。轨迹拟合基于时间戳, 倍速播放丢帧不影响精度。

## 算法要点

- **运动检测** (WebGL2, `src/gl/MotionDetector.ts`): 灰度化(夜间模式 gamma 提亮) →
  自适应背景差 + 帧差双阈值 → 3×3 腐蚀/膨胀开运算 → 掩膜回读。
- **跟踪** (`src/detect/tracker.ts`): 最近邻 + 匀速预测关联, 轨迹确认需 ≥4 次命中。
- **分类** (`src/detect/classify.ts`): 按净位移/速度/直线度/水平变向次数/面积变化区分
  下落物、树叶(飘摆)、飞鸟(水平+扇翅)、雨滴(极快竖直短促)。
- **回溯** (`src/detect/trajectory.ts`): 取轨迹**前 1.2 秒**做二次最小二乘拟合
  (避开终端速度造成的轨迹弯折), 沿拟合线向过去回溯至标定楼面四边形,
  双线性逆映射到 (楼层, 户号); 置信度由拟合残差/轨迹长度/回推距离合成。
- **标定** (`src/calib/geometry.ts`): 四边形双线性网格, 牛顿迭代求逆映射。
